# 福建美术与设计类志愿填报助手

这是一个可直接部署到 GitHub Pages 的静态 H5 工具。

## 在线发布

1. 在 GitHub 新建仓库。
2. 将本目录推送到仓库。
3. 进入仓库 `Settings -> Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`。
5. `Branch` 选择 `master` 或 `main`，目录选择 `/root`。

发布后访问：

`https://你的GitHub用户名.github.io/仓库名/`

## 入口文件

- `index.html`：GitHub Pages 首页
- `assets/h5-hero.png`：H5 首屏图片
- `fujian-art-volunteers.csv`：默认导出的 CSV 文件
- `outputs/`：维护用原始页面、底稿、分析和维护记录
